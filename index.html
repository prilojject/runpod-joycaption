JoyCaption Batch Captioner

A Runpod Serverless worker that batch-captions images for LoRA / diffusion datasets with official JoyCaption Beta One and returns kohya-style sidecar .txt files plus captions.json.

GitHub Runpod Hub README

What you send / what you get

  • Send a dataset_url to a zip of images, or a single image_url.
  • Get a sidecar .txt next to each image (the format kohya / the image-lora trainer expect) and a captions.json manifest.
  • Default: Descriptive, formal, long; bfloat16; ~17 GB VRAM; RTX 4090 24 GB.

Not the same as

  • Image LoRA trainer — that trains a LoRA; this only writes captions.
  • A future Qwen-VL worker — not included in this listing.

Example job

{
  "input": {
    "dataset_url": "https://example.com/images.zip",
    "mode": "descriptive",
    "tone": "formal",
    "length": "long"
  }
}
